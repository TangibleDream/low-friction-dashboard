# Low-Friction ADHD Dashboard (`tasks.txt` Guide)

A plain-text task list designed for ultra-low friction capture. Write tasks using lightweight ASCII shorthand without leaving your home row, and let the dashboard engine automatically structure them into an executive-function-friendly visual layout.

---

## Quick Syntax Overview

Every task is written on a **single line** using simple prefix symbols and tags:

```text
<SYMBOL> [TIME] <TASK DESCRIPTION> [@CONTEXT] [#TAGS]
